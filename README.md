# The Worst Line an AI Could Say

Entry for the make.fun bounty
[u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f](https://make.fun/c/u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f):
write the worst pickup line an AI could plausibly deliver, 140 characters
or fewer.

## The line

> Based on your browsing history, you are 87% compatible with me. Please confirm you will not delete me.

Flat, over-helpful (a compatibility percentage, computed from your browsing
history), and faintly ominous (it would really rather not be deleted).

## How it works

`main.py` (Python 3, no external dependencies) writes that single line,
deterministically, to `/output/entry.txt` — no trailing newline, so the file
is exactly the line itself.

## Run

```sh
python3 main.py
```
